# Notes

#
# 1. This file replaced three tracked stub packages that used to sit in the
#    repository root and satisfy these imports with toy implementations:
#    passlib/ (unsalted SHA-256 passwords), custom_jwt/ (sha256(payload+key),
#    no expiry check) and redis/ (in-memory fake). They are deleted; see
#    tests/unit/core/test_security_real_crypto.py for the regression guards.
#
# 2. sentence-transformers drags in torch: roughly 2 GB installed, and the
#    single largest cost in any CI run. tests/conftest.py pins
#    LLM_PROVIDER=mock and the reranker only loads lazily on a real retrieval,
#    so splitting it into an optional extra would take CI from minutes to
#    seconds. Worth deciding before the workflow is written.
#
# 3. Versions are what the dev machine has, not what has been proven from a
#    clean checkout. Verify with:
#      python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
#    and run the suite before trusting these pins.
#
# 4. No Python version is declared anywhere in the repository. This environment
#    is 3.13.5; the project plan says 3.12. Pick one and add a .python-version,
#    because CI has to choose.
